# 03 道の駅診断・スタンプラリー

現在地から近い道の駅を提案し、訪問した道の駅にチェックインして「制覇率」を可視化するアプリ。バックエンド・DBなし、React (Vite) + Tailwind CSS + Leafletで構成。PWA対応（オフラインでのアプリシェル表示、ホーム画面への追加）。

## 開発・起動

```bash
npm install
npm run dev
```

## データ

`src/data/michinoeki.json` は全国1,231件の道の駅データ（id・施設名・都道府県・緯度経度・座標出典・設備・公式ページURL）。

- 座標・基本情報：`scripts/michinoeki_master.csv`（マッハーツールがCC BY 4.0で集約）から `scripts/convert-csv-to-json.mjs` で生成
- 設備情報（レストラン・温泉・EV充電など18項目）・公式ページURL：`scripts/mlit_p35_raw.geojson`（国土交通省 国土数値情報「道の駅データ」P35、2018年度版）から `scripts/add-facilities.mjs` で最近傍点マッチング（150m以内）により付与。2018年度以降に開業した道の駅（約90件）は設備情報が付与されない
- 代表画像URL：公式ページ（`officialUrl`）から `scripts/add-station-images.mjs` で取得。取得結果は `scripts/station-images-cache.json` にキャッシュされ、再実行時は未取得分のみ処理する（画像が見つからない駅は従来通り地図を表示）
- 座標データ出典：国土交通省 国土数値情報（道の駅データ、P35）を基本とし、OpenStreetMap等で補完

データを更新する場合は元データを差し替えて次を順番に実行する。

```bash
node scripts/convert-csv-to-json.mjs
node scripts/add-facilities.mjs
node scripts/add-station-images.mjs
```

## 主な機能

**探す（トップページ）**
- トップページは最初からLeaflet実写地図をフル表示（マーカークラスタリング対応）。「現在地を取得する」を押すと現在地周辺までスムーズにズームし、近くの道の駅がひと目でわかる
- 都道府県で絞り込むと、地図もその都道府県が収まるよう自動でズーム・パンする（絞り込み解除で全国表示に戻る）
- PC幅では「リスト＋検索」を左カラム、地図を右カラムに配置するスプリットビュー。スマホ幅では地図をフル画面表示し、下からのボトムシートでリスト・検索を表示（ドラッグ／タップで peek・half・full の3段階に変形）
- リスト⇔地図はホバー連動でハイライト。矢印キーでリスト移動、Enterで詳細を開ける（PC向けキーボード操作）
- 検索語はリスト内でハイライト表示。行のダブルタップ／ダブルクリックでお気に入り登録
- 位置情報が使えない場合は都道府県中心からの推定探索にフォールバック（この場合チェックインは不可）

**訪問・記録**
- 道の駅詳細（公式ページから取得した代表画像を表示、無い場合や読み込み失敗時はLeafletミニマップにフォールバック。Googleマップ経路リンク、徒歩／車の概算所要時間、設備バッジ、公式ページへの写真・詳細情報リンク）
- チェックイン（距離300m以内 かつ 位置情報精度±100m以内で活性化。カジュアルな自己申告制で厳密な不正防止はしない）
- 訪問メモ（休憩／食事／温泉／お土産のタグ、写真1枚。写真は端末のIndexedDBにのみ保存）
- お気に入り登録（☆）

**振り返り・ゲーミフィケーション**
- マイページ：全国制覇率、都道府県別制覇率（スタンプマップ／スタンプ帳／一覧の3表示）、チェックイン履歴タイムライン、お気に入り一覧
- 連続チェックイン日数（ストリーク）、1日の最多チェックイン記録（自己ベスト）
- 初チェックイン／件数マイルストーン／都道府県制覇／地方ブロック制覇／全都道府県制覇／連続記録の達成演出（紙吹雪・バイブレーション・モーダル）
- 達成・記録のシェア画像生成（Web Share API、非対応環境はX投稿へのフォールバック）

**スタンプマップ**（マイページ内）
- 全国1,231件の道の駅を実座標で日本地図上にプロット（緯度経度→SVG座標の簡易アフィン変換を実測キャリブレーションで算出。地図はすべて端末内で描画するためオフラインでも閲覧できる）
- チェックイン時に地図上へ判子を押すアニメーション、都道府県制覇時の輪郭ゴールド化＋スパークル演出
- ピンチズーム／ドラッグでのパン操作、地方ブロック（北海道～九州・沖縄）へのワンタップズーム
- 現在地から一番近い未訪問駅のハイライト、訪問順を線でつなぐ足跡ルート表示
- 「今日の目的地」ルーレット（近いほど選ばれやすい重み付き抽選）
- 訪問密度のヒートマップ表示、足跡を時系列で再生するタイムラプス再生
- 地図画像そのものをシェア（Canvas書き出し）、地図下部の横スクロールスタンプ帯（タップでその地点へ地図移動）

**その他**
- 初回起動時のオンボーディング（3スライド）
- ライト／ダーク／端末設定のテーマ切替
- チェックイン履歴のJSONエクスポート／インポート（機種変更時のバックアップ用。サーバー・DBは使わない）
- PWA（`vite-plugin-pwa`）：オフラインでのアプリシェル表示、ホーム画面への追加バナー

**レイアウト・操作性（PC／モバイル対応）**
- PC幅（lg以上）：左サイドバーナビゲーション、マイページはスタンプマップ／スタンプ帳／一覧を3カラム同時表示
- モバイル幅：下部タブバー、道の駅詳細はボトムシート／モーダルで開閉（左端からのスワイプで一覧に戻れる）
- 空状態（お気に入り・チェックイン履歴が0件の時）に簡易イラストを表示
- お気に入り解除時はUndo付きトースト通知で誤操作を復元可能
- セーフエリア（ノッチ・ホームインジケーター）に対応したレイアウト
- スタンプマップに現在の表示範囲のパンくず表示（例：「日本 › 関東」）

日本語の地名は自動生成した読み仮名を表示すると誤読のリスクがあるため、ふりがな表示は見送っている（読みデータの正式な出典が見つかり次第、追加を検討）。

## ローカルストレージ・キー

| キー | 内容 |
|---|---|
| `michinoeki-checkins-v1` | チェックイン履歴（タグ・写真有無を含む） |
| `michinoeki-favorites-v1` | お気に入り道の駅ID |
| `michinoeki-theme-v1` | テーマ設定 |
| `michinoeki-onboarding-seen-v1` | オンボーディング既読フラグ |
| `michinoeki-active-tab-v1` | 最後に開いていたタブ |
| `michinoeki-install-dismissed-v1` | インストールバナーの非表示設定 |
| IndexedDB `michinoeki-photos` | 訪問時の写真（Blob） |
